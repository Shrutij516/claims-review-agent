# POL-008: Physical therapy (CPT 97110) visit cap and functional goals

id: POL-008

> SYNTHETIC POLICY. This is a synthetic policy written for demo and testing
> purposes only. It is NOT a CMS document, not a Medicare coverage
> determination, and not a payer document. The visit cap is invented for this
> project.

## Criteria

POL-008.1 Physical therapy is capped at 12 visits per 60 day episode of care. The visit number within the episode should be documented in the clinical note.

POL-008.2 Each course of therapy must have documented functional goals, for example walking distance, stairs climbed, or return to a work task.

POL-008.3 Each visit is limited to 4 units of 97110 (60 minutes), as set out in POL-005.2.
