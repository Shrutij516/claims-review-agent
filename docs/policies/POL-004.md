# POL-004: Duplicate billing

id: POL-004

> SYNTHETIC POLICY. This is a synthetic policy written for demo and testing
> purposes only. It is NOT a CMS document, not a Medicare coverage
> determination, and not a payer document.

## Criteria

POL-004.1 A claim with the same patient, the same procedure code and the same rendering provider as an earlier claim, dated within 14 days of it, is treated as a possible duplicate and needs documented justification.

POL-004.2 Accepted justifications are a different body side shown by an RT or LT modifier, a new problem documented in the clinical note, or a repeat service required by a documented protocol. The justification must be in the clinical note.

POL-004.3 The same patient, procedure code and provider more than 14 days apart is not a duplicate under this policy.
