# POL-005: Units per code per day

id: POL-005

> SYNTHETIC POLICY. This is a synthetic policy written for demo and testing
> purposes only. It is NOT a CMS document, not a Medicare coverage
> determination, and not a payer document. The unit limits are invented for
> this project.

## Criteria

POL-005.1 The units billed on a line must not exceed the per-code daily limit listed in data/v2/flag_catalog.json.

POL-005.2 Time based codes are billed in 15 minute units. Code 97110 is limited to 4 units (60 minutes) per day.

POL-005.3 A line that is exactly at the limit is allowed. Only units above the limit are over the limit.
